# Co-folding inference: worked examples

Plain structure prediction with OpenDDE: you describe the molecules in an input
JSON (see [`docs/infer_json_format.md`](../../docs/infer_json_format.md) for every
field) and `opendde pred` writes the predicted complex. For antibody–antigen
prediction with partial interface knowledge, see [`examples/tfg`](../tfg).

## The cases

Each input differs in where its MSA and template features come from. Chain
lengths are in brackets; `count` is the number of copies.

| Input | Content | Features | Use it to |
| --- | --- | --- | --- |
| [`input.json`](input.json) | one protein chain (693) | none given; searched when enabled | the basic run |
| [`protein_200.json`](protein_200.json) | one synthetic protein chain (200) | none | time a run, or try Fold-CP, with `--use_msa false` |
| [`example.json`](example.json) | three jobs: `7r6r` (protein + 2 DNA strands), `7wux` (two protein entities × 2 copies, three ligand types incl. Mg), `7pzb` (protein, DNA, ligand) | precomputed protein MSA in [`msa/`](msa) through `msa.precomputed_msa_dir` | protein–nucleic-acid and ligand inputs with a ready MSA |
| [`example_without_msa.json`](example_without_msa.json) | `7pzb` again, with no MSA path | none; generated by `opendde prep` | the preprocessing workflow |
| [`template/example_9fm7.json`](template/example_9fm7.json) | protein (291) × 2 and ligand `CCD_ATR` × 2 | MSA and template files in [`template/9fm7`](template/9fm7) | precomputed MSA and templates |
| [`rna_msa/example_9gmw_2.json`](rna_msa/example_9gmw_2.json) | one RNA chain (86) | RNA MSA in [`rna_msa/9gmw`](rna_msa/9gmw) | the RNA MSA path |

[`structures/`](structures) holds a PDB (`7pzb.pdb`) and a CIF (`2lwu.cif`) that
`opendde json` converts to an input JSON.

## Requirements

- The OpenDDE package and its model checkpoint (see the main README).
- Run every command from the repository root. The inputs point to their MSA and
  template files through paths relative to it (`./examples/cofold/...`).
- `--use_msa true` with an input that has no MSA path starts an MSA search, which
  needs the search databases and tools described in
  [`docs/msa_template_pipeline.md`](../../docs/msa_template_pipeline.md).
  Inputs that carry their paths start no search.

## Run the examples

```bash
OUT=./cofold_demo

# 1. basic run, no external features
opendde pred -i examples/cofold/input.json -o $OUT/basic -n opendde_v1 \
  --use_msa false --use_template false --use_rna_msa false \
  --sample 1 --step 200 --cycle 10

# 2. precomputed MSA and templates
opendde pred -i examples/cofold/template/example_9fm7.json -o $OUT/template -n opendde_v1 \
  --use_msa true --use_template true --use_rna_msa false

# 3. precomputed RNA MSA
opendde pred -i examples/cofold/rna_msa/example_9gmw_2.json -o $OUT/rna -n opendde_v1 \
  --use_rna_msa true
```

Structures are written to `<out>/<job name>/seed_<seed>/predictions/`.

### Generate the MSA and templates

`example_without_msa.json` has no feature paths. `opendde prep` searches for them
and writes an updated JSON, whose path it logs:

```bash
opendde prep -i examples/cofold/example_without_msa.json -o $OUT/prep

opendde pred \
  -i $OUT/prep/.opendde_preprocessed/<input-hash>/example_without_msa-final-updated.json \
  -o $OUT/prep -n opendde_v1 \
  --use_msa true --use_template true --use_rna_msa false
```

Use `opendde msa` for the protein MSA only and `opendde mt` for the protein MSA
and templates only.

### Convert a structure to an input JSON

```bash
opendde json -i examples/cofold/structures/7pzb.pdb -o $OUT/json --altloc first
opendde json -i examples/cofold/structures/2lwu.cif -o $OUT/json --altloc first --assembly_id 1
```

### Several GPUs

`protein_200.json` is the input for the Fold-CP multi-GPU example in
[`docs/inference_instructions.md`](../../docs/inference_instructions.md).
